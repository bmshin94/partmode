              Help

              PartMode V8

              For people

              Open full HelpAbout PartMode
              1. Start a sketch. Choose Sketch for the base plane, or choose Extrude to select a supported flat face.
              2. Draw a closed profile. Place a rectangle, circle, or polygon. Select it to type exact dimensions.
              3. Make it solid. Enter the height and choose Apply. Every later feature appears in History.
              4. Configure it. Use CFG when a design table defines named part variants.
              5. Export it. Open Output for STEP, STL, AMF, 3MF, project, or SVG drawing output from the active settled configuration.
              1. Insert a component. Choose an embedded definition or another part saved in this browser. The new occurrence becomes selected.
              2. Place the component. Use its starting X, Y, and Z values for a rough position; mates own the final exact placement.
              3. Add a mate. Choose Anchor or Moving reference, then click the intended flat face in the viewport. The active face highlights blue.
              4. Check freedom. The component tree reports each occurrence's remaining degrees of freedom and the Mates group reports solver state.
              5. Inspect and export. Use exact interference, clearance, section, exploded-view, STEP, and drawing outputs only after the assembly has settled.

              For agents

              Set up hosted MCPOpen agent reference

              Typed access, visible authority: an agent key identifies a client but grants no project access. A person approves one visible, project-scoped session. The agent reads live cad_capabilities, inspects exact state, previews a typed transaction, and commits only the matching approved revision. Pointer or screen control is not required.

              Reference

              Sketching

              Rect and Circle: click two corners / centre then edge. Polygon: click each point, double-click to close. Select a shape to type exact X, Y, W, H or Ø in millimetres. Scroll to zoom the grid, Pan tool to move around.

              Features

              Extrude raises your sketch by a height. Cut removes material downward — "through all" drills the whole part. Revolve treats the sketch as a lathe profile: x is the radius from the axis, y is height, spun around the vertical. Fillet and Chamfer round or bevel edges; Shell hollows the part with picked opening faces. Patterns repeat a sketch as rows or rings. Define parameters (wall = 2.5) and type wall*2 in any dimension — change the parameter and the whole part rebuilds.

              Your files

              The project autosaves in this browser. "Save" downloads editable schema-5 project data; "Open" restores supported project JSON or STEP geometry. STEP preserves the tested names, bodies, placements, units, and assembly hierarchy. AMF and 3MF preserve named mesh objects and millimetre units, while STL exports selected mesh geometry without names or units.

              Configurations and drawings

              The active configuration drives rebuild, inspection, STEP, STL, AMF, 3MF, and drawing generation. Drawings combine exact OpenCascade HLR views with document-owned dimensions, tables, notes, and symbols. Standards-oriented sheets remain subject to engineering review.

              Straight answers

              Is it really free? Yes. PartMode is free to use and is intended to remain free. Its source is available under the repository license.

              Who makes PartMode? PartMode is made by Sphinx.

              Where does my design go? Project files, geometry, and recovery history stay on this device. If you opt into agent access and approve a session, PartMode relays only that session's typed commands and results transiently; it does not store the project.

              Privacy and cookies? PartMode uses essential browser storage for local CAD, a cookie for your cookie choice, an account-session cookie only if you sign in for agent access, and a short-lived security cookie only while connecting Google. It does not use analytics, advertising, or third-party tracking. Read the privacy notice or review cookie settings.

              Will it replace Fusion or SolidWorks? PartMode V8 adds persistent typed agent control to parametric parts, multiple bodies, advanced shapes, reusable components, mates, section and exploded views, inspection, configurations, structured STEP interchange, compact SVG drawings, and persisted A3 part-specific drawing recipes. It does not provide engineering simulation, manufacturing certification, CAM, native DWG output, or a full general drafting workbench. Large assemblies and software-rendered browsers use adaptive interaction quality, and imported STEP does not reconstruct vendor-native feature history, mates, or PMI.

              What runs underneath? OpenCascade, a 25-year-old industrial B-rep kernel compiled to WebAssembly, plus replicad and three.js. The PartMode source is public.

              Need the complete workflow? Open PartMode Help. Agents can read the same release-versioned corpus through MCP resources.

              Made something worth keeping? Save the editable project or export STEP, STL, AMF, 3MF, and SVG files directly to your device.

                      Drawing output

                      Print-ready PDF

                      Create a drawing set with reusable ISO, ANSI, or DIN profiles, controlled layers and line fonts, multiple ordered sheets, custom sizes, per-sheet scales, and exact hidden-line views. A project without a drawing set exports one A4 sheet.

                      Named projection views
                      Advanced · derived drawing views

                      Part documents can create persistent section, detail, auxiliary, crop, and break views from a standard or named projection. Cutting planes use one line per plane: origin X,Y,Z | normal X,Y,Z | sheet X-axis X,Y,Z | positive or negative.

                      Drawing standard and layers
                      Custom line fonts
                      Notes, balloons, revision clouds, and blocks

                      A manual balloon anchor uses exact projection coordinates; its label and all other annotations use sheet millimetres.

                      Associative placed dimensions

                      Select exactly two persistently named faces, edges, or vertices in the model, then capture them here. Resolution uses names only and never falls back to proximity or traversal order.

                      GD&T and tolerance stacks

                      Datum and frame anchors resolve persistent exact topology. Stack rows use LABEL|NOMINAL|PLUS|MINUS|DIRECTION and publish worst-case limits plus RSS. This is controlled reference content, not standards certification.

                      Imported model dimensions

                      The value and authored expression come from the selected unsuppressed model feature. Endpoints are explicit exact-view coordinates; this does not claim topology-associative placement.

                      Manufacturing callouts and symbols

                      Hole callouts and centers resolve persistent unsuppressed Hole Wizard features into the selected exact view. Weld and surface symbols retain authored exact-view anchors.

                      Reusable drawing blocks
                      Cut lists, hole tables, weld tables, and revision tables

                      Select one or more active structural-member features. Length and start/end cuts resolve from current exact geometry.

                      Body-axis mode measures each exact body's world-axis bounds. It does not derive structural-member end treatments.

                      Structural-member cut lists derive exact axial length, profile, material, and start/end treatment evidence. No length or cut angle is authored here.

                      View alignment

                      An explicit scale that cannot fit the current drawing is rejected instead of silently shrinking the model.
